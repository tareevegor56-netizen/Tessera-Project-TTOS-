🇬🇧 About the Project

TTOS (Troutal Tile OS) and the Tessera Project represent a long-term personal journey into Android system customization and mobile interface design.

The core of the project is a tile-based UI design (heavily inspired by the iconic Windows Phone aesthetic), reimagined for modern standards. The ultimate goal is to design a mosaic interface (TesseraUI), build a standalone launcher (TileUI), and explore future system-level integration.
💡 Naming Story (The "Sidewalk Tile" Origin)

  TTOS (Troutal Tile OS) — the initial technical code name born from a linguistic inside joke. It traces back to a random brain loop involving the Russian phrase for sidewalk tile (тротуарная плитка), which morphed through phonetic gibberish into Troutal Tile. It sounds hilarious, but it stuck!

 Tessera Project — the overarching brand for the design system and visual style (referencing mosaic tesserae) representing official public releases.

🗺️ Roadmap

   Phase 1 (Current): Master Kotlin syntax, object-oriented programming, and official Android fundamentals using Jetpack Compose.

Phase 2: Design and prototype the tile-based UI layout components.

Phase 3: Develop the standalone launcher (TileUI).

Phase 4: Explore system-level integration and custom ROM adaptation.
    
🇷🇺 О проекте

TTOS (Troutal Tile OS) и Tessera Project — это долгосрочный пет-проект, посвященный глубокой кастомизации Android и созданию уникального пользовательского интерфейса.

Главная концепция проекта — плиточный дизайн (вдохновленный легендарной эстетикой Windows Phone), переосмысленный на современный лад. Конечная цель — спроектировать мозаичный интерфейс (TesseraUI), превратить его в рабочий лаунчер (TileUI) и в перспективе изучить возможность системной интеграции.
💡 История названий

TTOS (Troutal Tile OS) — исторически первое кодовое имя проекта. Родилось из лингвистической шутки: в голове застряло русское словосочетание «тротуарная плитка», которое после забавных языковых трансформаций превратилось в англоязычную абракадабру Troutal Tile. Звучит странно, но закрепилось намертво!

Tessera Project — более серьезное зонтичное наименование для дизайн-системы и визуального стиля (отсылка к мозаичным тессерам), которое идеально подходит для будущих публичных релизов.
